# Vrinda-store-annual-report
📖 Description
This project presents an interactive dashboard analyzing Vrinda Store’s performance in 2022. It highlights sales trends, customer demographics, regional performance, and channel distribution to provide actionable business insights.

🚀 Features
Monthly Orders vs Sales trend visualization

Gender-based sales breakdown (Men vs Women)

Order status tracking (Delivered, Cancelled, Returned, Refunded)

Top 5 states by sales revenue

Age vs Gender order distribution

Channel-wise order share (Amazon, Flipkart, Myntra, etc.)

🛠️ Tech Stack
Excel / Power BI / Tableau (depending on what you used)

Data cleaning and preparation tools (if applicable)

📊 Insights
Women drive 64% of sales

Amazon leads with 35% of orders

Maharashtra tops state sales at ₹2.99M

Adults dominate order volume

92% of orders delivered successfully

📂 How to Use
Clone the repository

Open the dashboard file (.xlsx / .pbix / .twbx)

Explore filters for month, channel, and category
